# Dashboard Métricas de Negocio

Este repositorio contiene un archivo HTML con un dashboard interactivo para visualizar métricas clave de desempeño empresarial.

## ¿Qué incluye?

- Métricas financieras, operacionales, de satisfacción del cliente, desempeño del personal y ventas/marketing.
- Gráficas de barras animadas para visualización rápida.
- Interfaz responsiva y moderna.
- Código listo para usar y modificar.

## ¿Cómo usar?

1. Descarga o clona este repositorio.
2. Abre el archivo `dashboard-metricas.html` en tu navegador favorito.
3. Personalízalo según tus métricas o necesidades.
